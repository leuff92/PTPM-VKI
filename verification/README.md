# Проверка ЛР5

Проверено 10.11.2026 на Windows, Python 3.12.10.

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

3 — запуск программы. Все тесты выполняются без обращения в интернет.

Дополнительно проверен настоящий HTTP-запрос к учебной странице через сервер
на `127.0.0.1`: первый запуск добавляет три сообщения, повторный — ноль.
В SQLite остаются три записи, кириллица и HTML-теги сохраняются.
Запрос несуществующей страницы с HTTP 404 обрабатывается сообщением об ошибке
и кодом завершения 1. Программа проверена при запуске из другой рабочей папки.

`pip check` не обнаружил конфликтов зависимостей. В Python-файлах приложения
и тестов нет комментариев. Шпаргалка Word состоит из семи страниц;
все страницы проверены после преобразования в изображения.
