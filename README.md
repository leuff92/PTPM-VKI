# Лабораторная работа 4

Автор: **Веселков Лев**. Тема: **юнит-тестирование класса Converter**.

Решение по [заданию ЛР4](https://github.com/Redsus228/PTPM-VKI/tree/Lab_4).
Главный код находится в `converter.py`: один класс и один статический метод
`Converter.do(x: float) -> int`. Базы данных, интерфейсы и сервер здесь не нужны.

## Правила преобразования

На входе — вещественное число с одним знаком после десятичной точки.

| Вход | Действие | Пример |
| --- | --- | --- |
| x не меньше 100.7 | вернуть 1000 | 100.7 → 1000 |
| x больше 0, но меньше 100.7 | отбросить дробную часть | 65.7 → 65 |
| x равен 0 | вызвать ValueError | 0.0 → исключение |
| x от -30.4 включительно до 0, не включая 0 | int(x) минус 5 | -1.9 → -6 |
| x не больше -30.5 | вернуть -2000 | -30.5 → -2000 |

`int()` отбрасывает дробь к нулю, а не округляет: `int(-1.9) == -1`.
Дроби с большим количеством знаков, NaN и бесконечности не входят в оговорённый
в задании формат входа; дополнительной валидации в метод не добавлено.

## Запуск в PyCharm и Git Bash

Если нужна новая копия, открой Git Bash в папке, где ещё нет `PTPM_Lab4`:

```bash
git clone --branch Lab_4 https://github.com/leuff92/PTPM-VKI.git PTPM_Lab4
cd PTPM_Lab4
```

Открой папку проекта в PyCharm. В **Terminal → Git Bash** из корня проекта:

```bash
python -m venv venv
./venv/Scripts/python.exe main.py
```

Создание `venv` выполняется только один раз. Введи, например, `65.7` и нажми Enter.
Ожидается `Результат: 65`. При вводе `0.0` программа покажет ошибку.
Десятичный разделитель — точка. Если команда `python` недоступна,
для создания окружения можно использовать `py -3 -m venv venv`.

## Тесты

Все тесты:

```bash
./venv/Scripts/python.exe -m unittest discover -s tests -v
```

Только класс Converter:

```bash
./venv/Scripts/python.exe -m unittest tests.test_converter -v
```

В проекте **10 тестовых методов**: 6 проверяют Converter, 4 — консольный запуск.
Подтесты охватывают обычные числа, границы `100.6/100.7`, `-30.4/-30.5`,
`-0.1/0.0/0.1`, отрицательный ноль и точный тип `int`.

## Необязательная проверка покрытия

```bash
./venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./venv/Scripts/python.exe -m coverage run -m unittest discover -s tests -v
./venv/Scripts/python.exe -m coverage report
```

Программа и unittest используют только стандартную библиотеку Python.
Пакет coverage нужен исключительно для отчёта о покрытии.
Проверенное покрытие: **100% строк и ветвлений**, 21 оператор и 10 ветвлений.
Подробности — в [verification](verification).
