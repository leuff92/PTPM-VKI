## Что нужно было сделать

Выбрать одно учебное веб-приложение и проверить его работу через настоящий браузер. Для Search Filter нужно проверить поиск по получателю платежа, счёту и типу операции, сброс фильтров и пустой результат.

Класс `SearchFilterPage` хранит локаторы и выполняет действия на странице. Тесты вызывают его методы и сравнивают строки таблицы с ожидаемыми. Это паттерн Page Object Model.

| Файл | Назначение |
| --- | --- |
| `pages/search_filter_page.py` | Открытие страницы, ввод текста, выбор в списках, чтение таблицы и сброс |
| `tests/test_search_filter.py` | 12 проверок поведения фильтров |
| `requirements.txt` | Версия Selenium |
| `Шпаргалка_ЛР6_Веселков_Лев.docx` | Вопросы и ответы для защиты |

## Запуск в PyCharm через Local

Нужны Python 3.10 или новее, Google Chrome и доступ к учебному сайту. Selenium Manager автоматически подбирает драйвер Chrome. При первом запуске ему может понадобиться скачать драйвер.

Открой папку проекта в PyCharm через **File → Open**. Во вкладке **Terminal → Local** (PowerShell) в корне проекта подготовь окружение.

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `python` отсутствует, используй `py -3 -m venv venv`. Окружение достаточно подготовить один раз. В настройках интерпретатора PyCharm можно выбрать `venv\Scripts\python.exe`.

Запуск всех тестов.

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Ожидаемый результат — `Ran 12 tests` и `OK`. Браузер по умолчанию работает без окна. Чтобы показать преподавателю один тест с видимым Chrome, выполни две команды в PowerShell.

```powershell
$env:LAB6_SHOW_BROWSER = "1"
.\venv\Scripts\python.exe -m unittest discover -s tests -k reset -v
```

Параметр `-k reset` выбирает тест, в имени которого есть слово `reset`. Окно открывается на время теста и автоматически закрывается. Для возврата к запуску без окна выполни `Remove-Item Env:LAB6_SHOW_BROWSER`.

## Что проверяют тесты

| Сценарий | Что должно получиться |
| --- | --- |
| Страница без фильтров | Пять строк |
| Поиск получателя по части имени `internet` | Две строки InternetBill |
| Поиск получателя `Salary` | Одна строка с зарплатой |
| Счёт Cash | Три строки |
| Счёт Bank Savings | Две строки |
| Тип INCOME | Одна строка |
| Тип EXPENDITURE | Четыре строки |
| Поиск получателей расходов по `bill` | Три строки |
| Поиск `Salary` среди получателей расходов | Пустая таблица |
| Поиск `internet` по счёту Cash с типом EXPENDITURE | Одна строка |
| Несуществующий получатель | Пустая таблица |
| Сброс четырёх фильтров | Снова все пять строк |

При сравнении проверяются счёт, тип, получатель и сумма. Номер строки в таблице пересчитывается при фильтрации, поэтому он не входит в сравнение.

На сайте сброс выполняется очисткой двух полей и выбором All Accounts и All Types. Метод `reset_filters` делает эти действия через интерфейс.

Каждый тест открывает отдельную сессию Chrome в `setUp` и закрывает её в `tearDown`. При тайм-ауте загрузки класс страницы пробует открыть сайт ещё один раз. Тесты зависят от доступности сайта и его ресурсов. Если Selenium не найден, проверь, что тесты и установка зависимостей используют один и тот же Python из `venv`.
