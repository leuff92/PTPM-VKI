# Triangle Lab · PTPM-VKI

Учебный проект по дисциплине **«Технологии программирования»**. В нём
реализован вариант №1 лабораторной работы: программа определяет тип
треугольника по трём сторонам и подготавливает координаты вершин для поля
`100 × 100`.

## Что умеет программа

- Принимает стороны `A`, `B` и `C` в виде строк и безопасно преобразует их в
  `float`.
- Проверяет положительность, конечность числа и строгое неравенство
  треугольника.
- Возвращает один из результатов: `равносторонний`, `равнобедренный`,
  `разносторонний`, `не треугольник`.
- Вычисляет три целочисленные координаты, помещающиеся в границы `0…100`.
- Не завершает работу аварийно, если пользователь ввёл ошибочные данные.
- Записывает основные события одновременно в консоль и в файл журнала.

## Результат для разных входных данных

| Данные | Тип фигуры | Координаты |
| --- | --- | --- |
| Корректные стороны | Один из трёх типов треугольника | Три точки `(x, y)` внутри поля `100 × 100` |
| Числа, но треугольник невозможен | `не треугольник` | `[(-1, -1), (-1, -1), (-1, -1)]` |
| Не удаётся прочитать число | Пустая строка | `[(-2, -2), (-2, -2), (-2, -2)]` |

Примеры недопустимых числовых значений: ноль, отрицательная сторона,
`nan`, `inf` или значения, не проходящие неравенство треугольника.

## Быстрый старт в PyCharm

1. Откройте корневую папку проекта через **File → Open**.
2. В настройках проекта выберите Python 3.10 или новее.
3. Откройте `main.py` и запустите файл кнопкой `Run`.
4. Введите по очереди три стороны, например `3`, `4`, `5`.

Внешние библиотеки не нужны: используются только компоненты стандартной
библиотеки Python.

Пример работы:

```text
Введите сторону A: 3
Введите сторону B: 4
Введите сторону C: 5
Тип фигуры: разносторонний
Координаты вершин: [(12, 0), (88, 0), (87, 100)]
```

## Проверка проекта

Из встроенного терминала PyCharm или из командной строки в корневой папке
проекта выполните:

```bash
python -m unittest discover -s tests -v
```

Тесты покрывают три корректных вида треугольников, неравенство треугольника,
нечисловой ввод и особые значения `float`.

## Логирование и отладка

Конфигурация находится в `configure_logging()` в `main.py`. В каждой записи
указываются дата, время, уровень события, модуль и сообщение. Вывод идёт в:

- консоль — чтобы наблюдать за ходом запуска;
- `logs/file_txt.log` — чтобы сохранить историю вычислений.

Успешный запрос содержит стороны, тип и найденные координаты. Ошибочный ввод
записывается как ошибка; неожиданное исключение добавляется в журнал вместе с
полным traceback.
