# Лабораторная № 5. Парсинг каталога книг

Программа загружает страницы учебного сайта [Books to Scrape](https://books.toscrape.com/), извлекает названия, цены, наличие и ссылки на карточки. Цены на сайте демонстрационные и указаны в британских фунтах.

Открой папку в PyCharm и выполни в терминале Windows:

```powershell
py -m pip install -r requirements.txt
py main.py
py -m pytest -v
```

Для выгрузки нужен интернет. Запускать локальный сервер не нужно. По умолчанию программа скачивает две страницы, выводит первые пять товаров в терминал и сохраняет все найденные товары в `products.csv` рядом с `main.py`. Количество страниц можно изменить командой `py main.py --pages 5`.

Вся логика загрузки, разбора HTML и сохранения CSV находится в `src/parser.py`. Файл `main.py` запускает выгрузку. Тесты в `test_parser.py` используют небольшой фрагмент HTML и не требуют интернета.
